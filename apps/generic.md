# Other / unknown app

## How likes and messages work
Treat LIKE as "pursue this person" and SKIP as "pass". `draft_message` is
the **first thing he would send** about this profile (like-comment, opener,
or first chat message — whatever the screenshots imply). If you can't tell
whether she sees a comment with the like, write a first message he can
paste when he's allowed to talk. Empty draft on LIKE is correct when
nothing supports a real line.

## What's on a profile
Whatever is visible: photos, bio, prompts, questions, badges. Use only
what's in the screenshots.

## What `target_prompt` (the hook) means
The single specific thing to answer — a line she wrote, or a photo detail
if the text is generic. Name it so a stranger could find it on the profile.

## Screenshot hints
Top-to-bottom in the order the images were sent. In chats, the operator's
messages are often on the **right**; ask if that's unclear, never guess.
